# ElectroFix – Electrician Services Website

A modern, responsive website for a certified electrician, with online booking, complaint management, client reviews, and a secure admin dashboard.

## Features

### For Customers
- 📅 Online service booking with date and time selection
- 📝 Complaint submission with status tracking
- ⭐ Client reviews and ratings
- 📱 Fully responsive on mobile, tablet and desktop

### For the Admin
- 🔐 Secure admin login
- 📊 Dashboard to view and manage bookings
- 🛠️ Complaint management (review, update status, resolve)
- 💬 Review moderation
