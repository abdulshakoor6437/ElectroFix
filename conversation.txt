4. HOW TO RUN LOCALLY
--------------------------------------------------------------------------------
1. Ensure XAMPP MySQL is running on localhost:3306 with database "electrofix".
2. Run database setup & seeding:
     npx prisma db push
     npx prisma db seed
3. Start the Next.js development server:
     npm run dev
4. Open http://localhost:3000 for public website.
5. Open http://localhost:3000/admin/login for admin dashboard.
